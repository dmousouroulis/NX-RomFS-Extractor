# v0.1.1 testing

Before merging, verify on Android with a known base + update pair:

1. Select the base NSP.
2. Select the matching update NSP.
3. Select compatible `prod.keys`.
4. Tap **Browse RomFS** and confirm the reconstructed file browser opens.
5. Select a known source file.
6. Choose a writable output subfolder in internal storage or on an SD card.
7. Extract the file and verify the saved copy.

Also verify that selecting obviously reversed `[v...]` / `[v0]` filenames triggers the package-order warning.
